## 📦 Як запустити локально

1. Клонуйте репозиторій:
   ```bash
   git clone https://github.com/realLBERG/05_08.git
   ```
2. Перейдіть у папку:
   ```bash
   cd 05_08
   ```
3. Встановіть залежності:
   ```bash
   npm install
   ```
4. Запустіть сервер для розробки:
   ```bash
   npm run dev
   ```
